# Unit Test Instructions — u1-todo-app

## Command

`npm run test -- src/App.test.tsx src/storage.test.ts`

## Setup and targets

- Configure Vitest with jsdom, React Testing Library, and axe-core.
- Cover TODO creation, validation, restoration, completion state, completed
  visibility, read failure, write failure, retry, and keyboard/status behaviour.
- Run 5–8 tests for each implementation component and boundary.
- Build and Test checks the complete suite at 80% or higher line coverage.
