## 画面構成

1画面で TODO を管理する。白地を基調に、主要操作には明るい青緑のアクセントカラーを用いる。装飾は最小限にし、操作状態は色だけではなくテキスト、チェックマーク、取り消し線で示す。

### 通常状態

```text
+----------------------------------------------------+
| TODO                                               |
| 今日やることを記録して、完了したらチェックします。 |
|                                                    |
| [ TODO を入力                              ] [追加] |
| 入力は空白だけにできません。                        |
|                                                    |
| 未完了 (2)                                         |
| [ ] 買い物に行く                                   |
| [ ] レポートの下書きを書く                         |
|                                                    |
| [完了済みを表示]                                   |
+----------------------------------------------------+
```

- 入力欄と「追加」ボタンは同じ行に配置する。
- TODO は保存順に並び、未完了項目だけを初期表示する。
- 各 TODO の左にネイティブチェックボックスを置く。
- 追加成功時は入力を空にして入力欄へフォーカスを戻す。

### 完了済み表示を開いた状態

```text
未完了 (2)
[ ] 買い物に行く
[ ] レポートの下書きを書く

完了済み (1)
[x] 電気料金を支払う

[完了済みを非表示]
```

- 完了済み TODO は未完了一覧の下に表示する。
- 完了済み項目はチェック済み、取り消し線、状態テキスト「完了」で区別する。
- 「完了済みを表示／非表示」ボタンの文言は現在の状態を反映する。

### 空の状態

```text
未完了 (0)
まだ TODO はありません。
上の入力欄から、最初の TODO を追加してください。
```

### 入力エラー

```text
[ TODO を入力                              ] [追加]
TODO を入力してください。
```

- エラーは入力欄の直下に表示し、入力欄と `aria-describedby` で関連付ける。
- 入力値は消去しない。空白だけの値では追加しない。

### 保存失敗

```text
[保存できませんでした。画面上の変更は保持されています。再試行するか、
 ページを再読み込みしてください。] [再試行] [再読み込み]
```

- 保存失敗は画面上部のライブリージョンに表示する。
- 書き込み失敗時も表示済み TODO と入力値を保持する。
- 読み取り失敗時は同じ通知領域に理由を示し、追加と完了切り替えを無効化する。

## レスポンシブ表示

| 幅 | レイアウト |
|---|---|
| 375px | 余白16px。入力欄と追加ボタンを縦積みにし、ボタンは十分なタップ領域を確保する。 |
| 768px | 余白24px。入力欄と追加ボタンを横並びにし、本文は中央の読みやすい幅に収める。 |
| 1280px | 最大幅720pxの中央カラム。横並びの入力フォームを維持する。 |

## 状態遷移

| 操作 | 画面上の結果 |
|---|---|
| 有効な TODO を追加 | 1秒以内に未完了一覧へ表示し、入力欄を空にしてフォーカスを戻す。 |
| 未完了を完了にする | 1秒以内に未完了一覧から除外し、保存する。 |
| 完了を未完了に戻す | 1秒以内に未完了一覧へ戻し、保存する。 |
| 完了済みを表示する | 完了済みセクションを開き、区別可能な状態で表示する。 |
| 保存に失敗する | 画面上の変更を保持し、再試行または再読み込みを案内する。 |
