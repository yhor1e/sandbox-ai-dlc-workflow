# デザインシステム対応表

## 参照した入力

- `../requirements-analysis/requirements.md` — NFR2、NFR3 の対応環境と WCAG 2.2 AA
- `../user-stories/stories.md` — 追加、状態変更、保存失敗の画面要件
- `mockups.md` — 明るいアクセントカラーを使う1画面構成

既存のデザインシステムは指定されていないため、ブラウザ標準部品と小さな独自トークンで構成する。実装時に採用するフレームワークの部品ライブラリが決まっても、以下の意味とアクセシビリティ要件を保つ。

| UI 要素 | 推奨部品 | 用途 | 必須の性質 |
|---|---|---|---|
| ページシェル | `main` / `section` | 中央カラムと見出し | 読みやすい最大幅、見出し階層 |
| TODO 入力 | テキスト入力 | 新規 TODO の入力 | 可視ラベル、エラーとの関連付け |
| 追加 | 主ボタン | 有効な TODO を追加 | フォーカス可視化、無効状態 |
| TODO 項目 | リスト項目 | TODO 名と状態の表示 | 保存順、折り返し対応 |
| 完了切り替え | チェックボックス | 完了・未完了の変更 | TODO 名を操作名にする |
| 完了済み表示 | セカンダリボタン | 完了済みセクションの開閉 | 現在状態を文言と `aria-expanded` で示す |
| 入力エラー | インラインメッセージ | 空白入力の修正案内 | 色だけに依存しない、入力と関連付け |
| 保存通知 | ライブリージョン | 保存失敗と回復手段の案内 | 再試行・再読み込みの操作を含む |

## デザイントークン

| Token | 用途 | 方針 |
|---|---|---|
| `color.accent` | 主ボタン、フォーカスリング | 明るい青緑。白文字とのコントラスト4.5:1以上 |
| `color.text` | 本文、TODO 名 | 白背景とのコントラスト4.5:1以上 |
| `color.error` | 入力・保存失敗 | アイコンまたは説明文を併用し、色だけで意味を伝えない |
| `space.16` / `space.24` | モバイル・タブレットの余白 | 375pxでも内容を圧迫しない |
| `radius.8` | 入力欄、ボタン、通知 | 軽い親しみやすさを付与する |
| `focus.ring` | キーボードフォーカス | 背景と3:1以上のコントラストで明確に表示する |

## 禁止する表現

- 完了状態を色だけで示すこと
- プレースホルダーだけで入力欄の目的を示すこと
- 保存失敗時に画面上の変更または入力を消去すること
- 小さい画面で横スクロールを必要とするフォームを作ること
